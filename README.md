# kku-academic-doc-check

Agent Skill สำหรับตรวจและแก้ไขรายงาน / เค้าโครงโครงงานคอมพิวเตอร์ ของสาขาวิชาวิทยาการคอมพิวเตอร์ วิทยาลัยการคอมพิวเตอร์ มหาวิทยาลัยขอนแก่น
ให้ตรงตามแนวปฏิบัติการจัดพิมพ์ ภาษาวิชาการ แม่แบบเค้าโครง CP353761 และการอ้างอิง APA ฉบับ มข.

## โครงสร้าง
```
kku-academic-doc-check/
└── SKILL.md      # กฎทั้งหมด + ขั้นตอนการทำงาน + สคริปต์ตรวจ kku_check.py (ฝังอยู่ท้ายไฟล์)
```

## ติดตั้ง
- **Claude (claude.ai / แอป)**: zip โฟลเดอร์ `kku-academic-doc-check` → Customize → Skills → + → Create skill → Upload a skill (ต้องเปิด code execution)
- **Claude Code / Codex CLI / Gemini CLI / Cursor ฯลฯ**: คัดลอกโฟลเดอร์ `kku-academic-doc-check` ไปไว้ในโฟลเดอร์ skills ของเครื่องมือนั้น
- ต้องมี Python + `pip install python-docx pdfplumber`

สร้างไฟล์ zip สำหรับอัปโหลด:
```bash
zip -r kku-academic-doc-check.zip kku-academic-doc-check
```

## วิธีใช้
แนบไฟล์ `.docx` แล้วพิมพ์ เช่น “ตรวจรูปแบบเค้าโครงนี้ตามแบบ มข.” จะได้ไฟล์ `<ชื่อเดิม>_แก้ไข.docx` + สรุปสิ่งที่แก้แล้ว / ต้องแก้เอง

## แหล่งที่มาของกฎ
สรุปจาก: แนวปฏิบัติในการจัดพิมพ์เค้าโครงโครงงาน/รายงานโครงงานคอมพิวเตอร์, สไลด์การจัดทำเอกสารวิชาการและการเขียนอ้างอิง, คู่มือการเขียนอ้างอิงแบบ APA (มข.), แม่แบบเค้าโครงโครงงาน CP353761
(ไม่ได้ใส่ไฟล์ PDF ต้นฉบับไว้ใน repo เพราะเป็นเอกสารประกอบการสอน)
