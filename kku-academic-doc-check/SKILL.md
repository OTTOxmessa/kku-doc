# ตรวจและแก้ไขเอกสารวิชาการ มข. (สาขาวิทยาการคอมพิวเตอร์)

กฎทั้งหมดสรุปจากเอกสาร 4 ฉบับ:
- **[แนว]** แนวปฏิบัติในการจัดพิมพ์เค้าโครงโครงงาน/รายงานโครงงานคอมพิวเตอร์ (ผศ.ดร.สิลดา อินทรโสธรฉันท์)
- **[สไลด์]** การจัดทำเอกสารวิชาการและการเขียนอ้างอิง (สไลด์ประกอบการสอน + โจทย์ Ass 4)
- **[APA]** คู่มือการเขียนอ้างอิงแบบ APA (แบบที่ 1 ของ มข. — ดัดแปลงจาก APA ไม่ใช่ APA 7 ตรง ๆ)
- **[แม่แบบ]** เอกสารเค้าโครงโครงงาน — แม่แบบ Word ของรายวิชา CP353761 สัมมนาทางวิทยาการคอมพิวเตอร์ (กลุ่ม CS2569/…): ปก + แบบฟอร์มเสนอเค้าโครง 11 หัวข้อ + ช่องลงชื่อ

ถ้าเอกสารต้นฉบับกับกฎในไฟล์นี้ขัดกัน ให้ยึดเอกสารต้นฉบับ ถ้า [แม่แบบ] (ใหม่กว่า เฉพาะรายวิชา) ขัดกับ [แนว] ให้ดูหัวข้อ D และถ้าอาจารย์ที่ปรึกษาสั่งเป็นอย่างอื่น ให้ยึดคำสั่งอาจารย์

## ขั้นตอนการทำงาน

1. **รับไฟล์** — ใช้ .docx เป็นหลัก (แก้ได้). ถ้าได้ .pdf ตรวจได้แต่แก้อัตโนมัติไม่ได้ ให้บอกผู้ใช้และขอ .docx ถ้าต้องการให้แก้. Google Docs ให้ขอ export เป็น .docx. ถ้าไฟล์อยู่ในโฟลเดอร์บนเครื่องผู้ใช้ ให้ stage มาทำใน workspace แล้วเขียนผลกลับไปข้างไฟล์เดิม. ห้ามแก้ไฟล์ต้นฉบับ ให้สร้างไฟล์ใหม่ชื่อ `<ชื่อเดิม>_แก้ไข.docx`.
2. **ระบุชนิดเอกสาร** — `report` = รายงานแบบมีบท (เช่น Ass 4: บทที่ 1–3), `proposal` = เค้าโครงโครงงานตาม [แม่แบบ] (ปก + หัวข้อ 1–11), `generic` = อื่น ๆ. สคริปต์เดาให้อัตโนมัติ ถ้าเดาผิดให้ระบุ `--type`.
3. **รันสคริปต์ตรวจ** — เขียนโค้ดในหัวข้อ “สคริปต์” ท้ายไฟล์นี้ลงเป็น `kku_check.py` (ต้องมี `python-docx`, `pdfplumber`; ติดตั้งด้วย `pip install --break-system-packages` ถ้าไม่มี) แล้วรัน
   ```bash
   python3 kku_check.py รายงาน.docx                         # ตรวจอย่างเดียว
   python3 kku_check.py รายงาน.docx --fix รายงาน_แก้ไข.docx  # ตรวจ + แก้รูปแบบอัตโนมัติ
   python3 kku_check.py รายงาน_แก้ไข.docx                   # ตรวจซ้ำหลังแก้
   ```
   สิ่งที่สคริปต์ตรวจ: หน้ากระดาษ/ขอบ, เลขหน้า, ฟอนต์, ขนาด/ตัวหนาของชื่อบท–หัวข้อ–เนื้อหา, ชื่อตาราง/ภาพ (ตำแหน่ง เลข ตัวหนา เว้นวรรค), ขนาด/ตัวหนาของปกและหัวแบบฟอร์มเค้าโครง, ชื่อหน่วยงานเก่า, ส่วนประกอบตามแม่แบบ (ตารางแผนงาน ช่องลงชื่อ ช่องอาจารย์ตรวจ), วัตถุประสงค์ขึ้นต้นด้วย “เพื่อ”, คำไม่เป็นทางการ/สรรพนามบุรุษที่ 1, คำนำหน้านาม, คำสะกดที่แนวปฏิบัติระบุ, บทคัดย่อ (ห้ามอ้างอิง, คำสำคัญ 3–5 คำ, ความยาว), โครงสร้างตามโจทย์, รายการอ้างอิง (ไทยก่อนอังกฤษ, ลำดับอักษร, ปีในวงเล็บ, ช่องว่างหน้าเครื่องหมาย, ค้นเมื่อ/Retrieved, hanging indent) และจับคู่อ้างอิงในเนื้อหา ↔ ท้ายเล่ม.
   `--fix` แก้เฉพาะสิ่งที่ปลอดภัย: ขนาด A4 + ขอบ + เลขหน้า, ฟอนต์ทั้งเล่ม, ขนาด/ตัวหนาของหัวข้อ, ขนาดเนื้อหา 14, จัดรูปแบบชื่อตาราง/ภาพ, ลบวรรคหน้าเครื่องหมายในรายการอ้างอิง, hanging indent, ย้ายรายการอ้างอิงภาษาไทยขึ้นก่อน, `et al` → `et al.`, “วิทยาศาสตรบัณฑิต”, ลบวรรคหลัง ผศ./รศ./ดร.
   ผลของสคริปต์เป็น heuristic — ข้อ ⚠️ ต้องตรวจซ้ำด้วยการอ่านจริงก่อนรายงาน อย่าส่งต่อผลที่ผิดพลาด (false positive) ให้ผู้ใช้.
4. **ตรวจด้วยการอ่าน** — อ่านเนื้อหาทั้งเล่ม (`python-docx` หรือ `pandoc`) แล้วไล่ checklist ในหัวข้อ “สิ่งที่ต้องตรวจด้วยคน” ข้างล่าง. สำหรับเรื่องหน้าตา (ปก, ตาราง, ภาพ, ย่อหน้า) ให้แปลงเป็น PDF (`soffice --headless --convert-to pdf`) แล้ว render หน้าที่เกี่ยวข้อง (`pdftoppm -r 60 -png`) มาดู. หมายเหตุ: ถ้าเครื่องไม่มีฟอนต์ TH Sarabun New ภาพจะแสดงด้วยฟอนต์อื่น — ตัดสินเรื่องฟอนต์จากผลสคริปต์ ไม่ใช่จากภาพ.
5. **แก้ไขเนื้อหา** (หลัง `--fix`) ด้วย python-docx บนไฟล์ `_แก้ไข.docx`:
   - แก้ภาษา/วรรคตอน/รูปแบบรายการอ้างอิงได้ แต่ **ห้ามเปลี่ยนความหมาย ตัวเลข ข้อเท็จจริง หรือผลการศึกษา**
   - **ห้ามแต่งข้อมูลบรรณานุกรมขึ้นเอง** (สำนักพิมพ์ เลขหน้า ปี วันที่ค้น) — ถ้าขาด ให้ใส่ `[ต้องเติม: สำนักพิมพ์]` แล้วแจ้งผู้ใช้
   - ข้อความภาษาไทยใน Word ใช้คุณสมบัติ complex script: ฟอนต์ `w:rFonts/@w:cs`, ขนาด `w:szCs`, ตัวหนา `w:bCs` — ตั้งทั้งคู่ (sz/szCs, b/bCs) ไม่อย่างนั้นข้อความไทยจะไม่เปลี่ยน
   - ถ้าผู้ใช้อยากเห็นว่าแก้อะไร หรือเป็นการแก้ถ้อยคำจำนวนมาก ให้ทำเป็น tracked changes (ใช้ docx skill ถ้ามี)
   - เรื่องที่ต้องตัดสินใจเชิงเนื้อหา (เพิ่มหัวข้อที่ขาด, เขียน synthesis matrix, ย่อบทคัดย่อ) ให้เสนอร่างและถามก่อนใส่
6. **ตรวจซ้ำและส่งมอบ** — รันสคริปต์กับไฟล์ที่แก้แล้วอีกครั้ง, ส่งไฟล์ `_แก้ไข.docx` กลับ (ไว้ข้างไฟล์เดิมถ้ามาจากโฟลเดอร์ของผู้ใช้) และสรุปในแชตตามรูปแบบใน “รายงานผล”.

## สิ่งที่ต้องตรวจด้วยคน (สคริปต์ตรวจไม่ได้หรือตรวจได้ไม่ครบ)

- **ปก** [แนว 1–3, สไลด์ 3.1]: มีชื่อเรื่อง ชื่อผู้จัดทำ (นาย/นาง/นางสาว + ชื่อ-สกุล + รหัส) รายวิชา คณะ มหาวิทยาลัย ภาคและปีการศึกษา; ชื่อเรื่องภาษาอังกฤษบนปกเป็นตัวพิมพ์ใหญ่ทั้งหมด (ยกเว้นศัพท์เฉพาะที่อาจารย์เห็นชอบ); ชื่อยาวเกิน 2 บรรทัดจัดเป็นสามเหลี่ยมกลับหัว (บรรทัดบนยาวสุด); ตำแหน่งวิชาการอาจารย์ถูกต้อง; ชื่อปริญญา/สาขาสะกดถูก.
- **ภาษาวิชาการ 6 ประการ** [สไลด์ 2]: ทางการ (ไม่มีภาษาพูด คำแสลง คำย่อไม่สากล สำนวน), ปรนัย (ไม่ใช้ “ผม/ฉัน/ผู้วิจัยคิดว่า”), ถูกต้องแม่นยำ (ระบุตัวเลข/ขอบเขตแทน “เยอะมาก” “เร็ว ๆ นี้”), กระชับ (ตัดคำซ้ำซ้อน), เป็นระบบ (มีคำเชื่อม นอกจากนี้/อย่างไรก็ตาม/ดังนั้น), มีหลักฐานอ้างอิงทุกข้อความที่ไม่ใช่ความคิดผู้เขียน. ศัพท์เฉพาะต้องอธิบาย/นิยามก่อนใช้.
- **คำภาษาอังกฤษแทรก** [แนว 5.1]: เลือกรูปแบบตัวพิมพ์แบบเดียวทั้งเล่ม — `Median Filter` หรือ `Median filter` หรือ `median filter`.
- **ย่อหน้าและหัวข้อ** [แนว 6 + ตัวอย่างหน้า 7–8]: หัวข้อแต่ละระดับเยื้องเป็นระบบเดียวกันทั้งเล่ม — หัวข้อใหญ่ชิดซ้าย, หัวข้อย่อยระดับ 1 เยื้องตรงกับตัวอักษรแรกของหัวข้อใหญ่, ระดับ 2 (เช่น 4.1.1) และระดับ 3 (เช่น (1), (2)) เยื้องลึกลงตามลำดับ; ย่อหน้าเนื้อหาเยื้องเข้าตามระดับหัวข้อที่สังกัด; เว้นหลังเลขหัวข้อเป็นระบบเดียวกัน (ตัวอย่าง: หลังเลขหัวข้อใหญ่เว้นหลายเคาะ, หลังเลขหัวข้อย่อยเว้น 2 เคาะ); ข้อความจัดกระจายให้เรียบร้อย.
- **ตาราง/ภาพ** [แนว 8–9]: ตารางที่ยาวไม่เกิน 1 หน้าต้องอยู่หน้าเดียว (แยกหน้าได้เฉพาะตารางที่ยาวเกิน 1 หน้า) และหน้าที่ต่อต้องพิมพ์เลข+ชื่อตารางซ้ำตามด้วย “(ต่อ)”/“(Cont.)”; ชื่อยาวเกิน 1 บรรทัด บรรทัดถัดไปเริ่มตรงตัวอักษรแรกของชื่อ; เว้น 1 บรรทัดระหว่างเนื้อหา–ชื่อตาราง–ตาราง และระหว่างภาพ–ชื่อภาพ–เนื้อหา; ตาราง/รายละเอียดที่ยาวมากควรย้ายไปภาคผนวก [สไลด์ 5]; ทุกตาราง/ภาพต้องถูกกล่าวถึงในเนื้อหา และมีใน สารบัญตาราง/สารบัญภาพ พร้อมเลขหน้าที่ตรง.
- **สารบัญ**: หัวข้อและเลขหน้าตรงกับเนื้อหาจริง.
- **บทคัดย่อ** [สไลด์ 4]: ครบ 5 ส่วน — (1) ที่มา 1–2 ประโยค + วัตถุประสงค์ 1 ประโยค (2) วิธีดำเนินการ: กลุ่มตัวอย่าง/ข้อมูล เครื่องมือ วิธีวิเคราะห์ (3) ผล — ชัดที่สุด มีตัวเลข/สถิติ (4) สรุปและการนำไปใช้ (5) คำสำคัญ 3–5 คำ; ยาว 150–250 คำหรือไม่เกิน 1 หน้า; ไม่มีการอ้างอิง; คำย่อต้องมีคำเต็มก่อน; ไม่มีทฤษฎียาว ๆ.
- **คำนำ** [สไลด์ 1.3]: บอกวัตถุประสงค์ของรายงาน อาจขอบคุณผู้ช่วยเหลือ แต่ไม่ “ออกตัว/แก้ตัว”. กิตติกรรมประกาศไม่เกิน 1 หน้า.
- **เนื้อหาตามโจทย์ Ass 4** [สไลด์ 35–39]: 2.1 งานวิจัยที่เกี่ยวข้องอธิบายแต่ละงานด้วย 5W1H; 2.3 เปรียบเทียบผลการศึกษาด้วย **ตาราง synthesis matrix + คำบรรยาย (literature review)**; บทที่ 3 มี 3.1 สรุปผล และ 3.2 แนวทางการนำไปใช้ (ต่อยอดโครงงาน). แต่ละบทสมบูรณ์ในตัว ไม่กระโดดไปมา.
- **เนื้อหาเค้าโครงตาม [แม่แบบ]** (คำอธิบายใต้แต่ละหัวข้อในแม่แบบคือสิ่งที่ต้องเขียน — ถ้ายังเหลือข้อความคำอธิบาย/จุดไข่ปลาของแม่แบบค้างอยู่ ให้แจ้ง):
  2 หลักการและเหตุผล — ปัญหา ความเป็นมา แนวคิดเบื้องต้น เหตุผลและความจำเป็น **มีการอ้างอิงแหล่งที่มา**; 3 วัตถุประสงค์ — ระบุผลลัพธ์ที่ได้ชัดเจน เป็นข้อ 3.1, 3.2 … ขึ้นต้น “เพื่อ…”; 4 ทฤษฎีและผลงานวิจัย — จากแหล่งที่น่าเชื่อถือ; 5 วิธีดำเนินการ — เป็นขั้นตอน 5.1, 5.2 … (ศึกษาทฤษฎี/เครื่องมือ, กำหนดขอบเขต, เตรียมข้อมูล, ออกแบบ, พัฒนา, ทดสอบ, สรุปผล, เขียนรายงาน, นำเสนอ); 6 ขอบเขตและข้อจำกัด — ขอบเขต = สิ่งที่ทำได้และทำได้ดีที่สุด, ข้อจำกัด = สิ่งที่ทำไม่ได้, เป็นข้อ 6.1, 6.2 …; 7 สถานที่ — ค่าเริ่มต้น “สาขาวิชาวิทยาการคอมพิวเตอร์ วิทยาลัยการคอมพิวเตอร์ มหาวิทยาลัยขอนแก่น”; 8 ประโยชน์ — จากการนำไปใช้ในอนาคต; 9 แผนงาน — ตาราง Gantt รายเดือน แถว = ขั้นตอนเดียวกับข้อ 5 ทุกขั้น พร้อม “ตารางที่ n แผนและระยะเวลาดำเนินการ” และหมายเหตุช่วงเวลา; 10 งบประมาณ — หมวดวัสดุอุปกรณ์ / ค่าใช้สอย / ค่าใช้จ่ายอื่น ๆ; 11 เอกสารอ้างอิง — APA และทุกรายการต้องถูกอ้างในข้อ 2/4; ท้ายเอกสาร: ลงชื่อผู้ทำโครงงานครบทุกคน (ชื่อในวงเล็บ + วันที่) และช่อง “การตรวจสอบจากอาจารย์ที่ปรึกษาโครงงาน” (☐ ตรวจสอบแล้ว เห็นชอบตามเสนอ / ☐ อื่น ๆ, ลงชื่อ, วันที่).
- **จริยธรรม** [สไลด์ 5]: ไม่มีข้อความที่ยกมาโดยไม่อ้างอิง; มีการเปิดเผยข้อจำกัด (ถ้าเป็นงานวิจัย).
- **อ้างอิง**: รูปแบบรายการตามชนิดเอกสาร (หนังสือ/วารสาร/เว็บ/การประชุม/วิทยานิพนธ์) ตามหัวข้อ C ข้างล่าง; ใช้ระบบเดียวทั้งเล่ม (ชื่อ-ปี หรือ ตัวเลข); ผลจับคู่ของสคริปต์ที่ขึ้นว่า “ไม่พบ” ให้ตรวจเองก่อน เพราะชื่อไทยที่ไม่มีวรรคอาจจับผิด.

### C. การอ้างอิง [APA ฉบับ มข.]
**ในเนื้อหา (ชื่อ-ปี)**
- ผู้แต่งไทยเขียนเอกสารไทย: ชื่อ + สกุล — `รังสรรค์ ธนะพรพันธุ์ (2548)` / `(รังสรรค์ ธนะพรพันธุ์, 2548)`; ต่างชาติหรือคนไทยเขียนภาษาอังกฤษ: สกุลเท่านั้น — `Patten (2005)` / `(Patten, 2005)`
- 2 คน: อ้างทั้งสองทุกครั้ง — นอกวงเล็บใช้ “และ/and”, ในวงเล็บใช้ “&”: `Enger and Smith (2004)` / `(Enger & Smith, 2004)`
- 3–5 คน: ครั้งแรกใส่ทุกคน ครั้งต่อไปใช้คนแรก + “และคณะ / et al.”; 6 คนขึ้นไป: ใช้ “และคณะ / et al.” ตั้งแต่ครั้งแรก. `et al.` มีจุด ไม่เอียง
- หน่วยงาน: ครั้งแรกชื่อเต็ม + [ชื่อย่อ] — `World Health Organization [WHO] (2007)` แล้วใช้ `WHO (2007)`
- ไม่มีผู้แต่ง → ใช้ชื่อเรื่อง; ไม่มีปี → ม.ป.ป. / n.d.; ระหว่างตีพิมพ์ → ระหว่างตีพิมพ์ / in press
- ผู้แต่งเดียวกันปีเดียวกัน → 2547ก, 2547ข / 1992a, 1992b; หลายเรื่องในวงเล็บเดียว เรียงตามอักษร คั่นด้วย `;`
- ระบุหน้า: `(อมรา พงศาพิชญ์, 2549, หน้า 32)` / `(Patten, 2005, p. 123)`
- อ้างซ้อน: `Pratt (1992 อ้างถึงใน ปราโมทย์ ธีรพงษ์, 2541)` หรือ `(…, 2541 อ้างจาก Pratt, 1992)`
- สื่อสารส่วนบุคคล/อีเมล/สัมภาษณ์ส่วนตัว: อ้างในเนื้อหาเท่านั้น `(D. Ellis, personal communication, June 2, 2007)` ไม่ใส่ท้ายเล่ม
- แบบตัวเลข [1] ใช้ได้ (cited-order = เรียงท้ายเล่มตามลำดับที่อ้าง; reference-order = เรียงท้ายเล่มตามอักษร) แต่ต้องใช้ระบบเดียวทั้งเล่ม

**ท้ายเล่ม**
- หัวข้อ “เอกสารอ้างอิง/References” = เฉพาะที่อ้างในเนื้อหา (จำนวนต้องตรงกัน); “บรรณานุกรม/Bibliography” = ใส่เอกสารที่ไม่ได้อ้างเพิ่มได้
- เรียง **ไทยทั้งหมดก่อน แล้วอังกฤษ**, เรียงตามอักษรชื่อผู้แต่ง (แบบพจนานุกรม); ผู้แต่งเดียวกันเรียงตามปี; รายการถัดไปของผู้แต่งคนแรกคนเดิมให้พิมพ์ `______.` แทนชื่อ (ใช้กับผู้แต่งคนแรกเท่านั้น)
- ชื่อผู้แต่งไทย: ชื่อ สกุล ไม่ใส่คำนำหน้า/ยศ/ตำแหน่ง/คุณวุฒิ (บรรดาศักดิ์ย้ายไปท้าย `สุชาดา กีระนันทน์, คุณหญิง.`); ต่างชาติ: `สกุล, อักษรย่อ.` เช่น `Sharp, G. D.`; 2–5 คนคั่น `,` และ `&` ก่อนคนสุดท้าย; 6 คนใส่ครบ, เกิน 6 ใส่ 6 คนแรก + `et al.`/`และคณะ`

- คำย่อ: ed., 2nd ed., Ed./Eds., Trans., n.d., p./pp., Vol., No.; ไม่มีสถานที่พิมพ์ [ม.ป.ท.]/[n.p.], ไม่มีสำนักพิมพ์ [ม.ป.พ.]/[n.p.], ไม่มีปี [ม.ป.ป.]/[n.d.]; ตัด บริษัท/จำกัด/Ltd./Inc. จากชื่อสำนักพิมพ์

- การพิมพ์: เครื่องหมายทุกตัวพิมพ์ชิดตัวหน้า ไม่เว้นวรรคหน้าเครื่องหมาย (`(2541).` ไม่ใช่ `(2541 ).`); เครื่องหมาย . , : ; ไม่หนา ไม่เอียง; บรรทัดที่ 2 เป็นต้นไปเยื้องเข้า 4–8 ตัวอักษร (hanging indent); ไม่ต้องตัดคำเพื่อให้ขอบขวาตรง

### D. จุดที่เอกสารต้นฉบับขัดกัน — แจ้งผู้ใช้แทนการตัดสินเอง
- **เว้นวรรคหลังเครื่องหมายในรายการอ้างอิง**: [แนว 7.3] ให้เว้น 2 เคาะหลัง . , : ; ทุกตัว แต่ [APA 2.3.3] ให้เว้น 2 เคาะหลัง . และ 1 เคาะหลัง , : ;. ค่าเริ่มต้นของ skill นี้: **ยึด [แนว] (แนวปฏิบัติของรายวิชา)** และตรวจแค่ความสม่ำเสมอ — ไม่แก้อัตโนมัติ เพราะต้องแยกจุดในอักษรย่อชื่อ (J.N.) และ URL ออก
- [APA] ตั้งชื่อว่าอิง APA 7th แต่กฎหลายข้อเป็นแบบ มข. (เช่น 3–5 คนอ้างครบครั้งแรก, ใส่สถานที่พิมพ์, ครั้งที่พิมพ์อยู่หลังชื่อเรื่อง, “Retrieved … from”) — **ให้ยึดคู่มือ มข. ไม่ใช่ APA 7 มาตรฐาน**
- การเว้นหลังเลขหัวข้อในตัวอย่าง [แนว] ไม่ได้ระบุเป็นตัวเลขชัดเจน — ตรวจแค่ว่าใช้แบบเดียวกันทั้งเล่ม
- **ฟอนต์**: [แนว] กำหนด TH Sarabun New แต่ไฟล์ [แม่แบบ] ใช้ TH SarabunPSK. ค่าเริ่มต้น: ยึด [แนว] — สคริปต์จะเตือน (ไม่ถือว่าผิด) ถ้าเจอ TH SarabunPSK และ `--fix` จะเปลี่ยนเป็น TH Sarabun New; ถ้าผู้ใช้/อาจารย์บอกให้ใช้ PSK ให้แก้ค่า `FONT` ในสคริปต์
- **ขนาดกระดาษ**: ไฟล์ [แม่แบบ] ตั้งเป็น Letter แต่ [แนว] กำหนด A4 — ยึด A4
- **ชื่อหน่วยงาน/หลักสูตร**: ตัวอย่างใน [แนว] ใช้ “ภาควิชาวิทยาการคอมพิวเตอร์ คณะวิทยาศาสตร์” และ “หลักสูตรวิทยาศาสตรบัณฑิต สาขา…” แต่ [แม่แบบ] ใช้ “สาขาวิชาวิทยาการคอมพิวเตอร์ วิทยาลัยการคอมพิวเตอร์” และ “หลักสูตรวิทยาการคอมพิวเตอร์” — ยึด [แม่แบบ]
- ข้อ 11 ใน [แม่แบบ] เขียนว่า “อ้างอิงตามแบบสากล” — ใช้ APA ตาม [APA]/[สไลด์]

## รายงานผล (ตอบในแชต)
สั้น อ่านง่าย ภาษาไทย:
1. บรรทัดแรก: ชนิดเอกสาร + จำนวนจุดที่แก้แล้ว / ที่ยังต้องแก้เอง
2. “แก้ให้แล้ว” — รวมเป็นกลุ่ม (หน้ากระดาษ, ฟอนต์, หัวข้อ, ตาราง/ภาพ, อ้างอิง, ภาษา) ไม่ต้องไล่ทีละ run
3. “ต้องแก้เอง/ต้องตัดสินใจ” — ระบุตำแหน่ง (บท/หัวข้อ + ข้อความสั้น ๆ) และวิธีแก้; ข้อมูลอ้างอิงที่ขาดให้บอกว่าขาดอะไร
4. ถ้ามีจุดในหัวข้อ D ที่เกี่ยวข้อง ให้บอกว่าใช้ค่าไหนและเปลี่ยนได้
ส่งไฟล์ `_แก้ไข.docx` พร้อมข้อความหนึ่งบรรทัด ไม่ต้องอธิบายเนื้อหาไฟล์ซ้ำ.

## สคริปต์ `kku_check.py`
เขียนโค้ดนี้ลงไฟล์ตามที่เป็น (ไม่ต้องดัดแปลง เว้นแต่พบบั๊ก):

```python
#!/usr/bin/env python3
"""ตรวจรูปแบบเอกสารวิชาการ สาขาวิทยาการคอมพิวเตอร์ มข. (docx / pdf)

usage: python3 kku_check.py INPUT [--type auto|report|proposal|generic]
                            [--fix OUT.docx] [--json OUT.json]
"""
import argparse, json, re, sys
from collections import Counter

FONT = "TH Sarabun New"
ALT_FONTS = ["TH SarabunPSK"]            # แม่แบบเค้าโครงของรายวิชาใช้ตัวนี้ — ยอมรับแต่เตือน
A4 = (8.27, 11.69)                      # inch
MARGINS = dict(top=1.5, left=1.5, right=1.0, bottom=1.0)
HEADER_DIST = 0.5                        # เลขหน้าห่างขอบบน 0.5"
TOL = 0.06

FRONT = ["บทคัดย่อ", "คำนำ", "กิตติกรรมประกาศ", "สารบัญ", "สารบัญตาราง",
         "สารบัญภาพ", "สารบัญรูป", "เอกสารอ้างอิง", "บรรณานุกรม", "ภาคผนวก",
         "abstract", "acknowledgements", "acknowledgement", "contents",
         "table of contents", "references", "bibliography", "appendix"]
REF_HEADS = ["เอกสารอ้างอิง", "บรรณานุกรม", "references", "bibliography"]
RE_CHAPTER = re.compile(r"^(บทที่\s*\d+|chapter\s+\d+)", re.I)
RE_CAPTION = re.compile(r"^(ตารางที่|ภาพที่|รูปที่|table|figure)\s*([\d.]+)", re.I)
RE_YEAR = r"(?:\d{4}[a-zก-ฮ]?|ม\.ป\.ป\.|n\.d\.|in press|ระหว่างตีพิมพ์)"
INFORMAL = ["เจ๋ง", "เยอะ", "เห็นๆ", "เร็วๆ นี้", "มากๆ", "โคตร", "แบบว่า", "ครับ",
            "ค่ะ", "นะคะ", "จ้า", "ชิลล์", "เวิร์ค", "เวิร์ก", "โอเค", "ประมาณว่า",
            "อะไรประมาณนี้", "สุดๆ", "ปังมาก", "ง่ายๆ", "ทำนองนี้"]
PERSONAL = ["ผม", "ฉัน", "ดิฉัน", "กระผม", "หนู", "พวกเรา", "ข้าพเจ้า", "ผู้วิจัยคิดว่า",
            "รู้สึกว่า", "คิดว่า"]
THAI = re.compile("[" + chr(0x0E00) + "-" + chr(0x0E7F) + "]")
MARKS = "[" + chr(0x0E31) + chr(0x0E34) + "-" + chr(0x0E3A) + chr(0x0E47) + "-" + chr(0x0E4E) + "]"
LATIN = re.compile(r"[A-Za-z]")

issues = []      # dict(sev, cat, msg, where)
fixed = []


def add(sev, cat, msg, where=""):
    issues.append(dict(sev=sev, cat=cat, msg=msg, where=where))


def norm(t):
    t = (t or "").replace(chr(0x0E4D) + chr(0x0E32), chr(0x0E33)).replace(chr(0xA0), " ").replace(chr(0x200B), "")
    t = re.sub(r"\s+(?=" + MARKS + ")", "", t)        # วรรคหลงหน้าสระ/วรรณยุกต์ (PDF)
    t = re.sub("(" + MARKS + ")\\1+", r"\1", t)        # สระ/วรรณยุกต์ซ้อน
    return t.strip()


def snip(t, n=45):
    t = norm(t)
    return t if len(t) <= n else t[:n] + "…"


def is_front(t):
    t = norm(t).rstrip(":").strip().lower()
    return t in FRONT


def classify(texts, has_chapters):
    """คืน list ของชนิดย่อหน้า: cover/title/chaptername/h1/h2/caption/body/empty"""
    kinds, seen_struct, prev, last_main = [], False, None, 0
    for t in texts:
        t = norm(t)
        k = "body"
        if not t:
            k = "empty"
        elif is_front(t) or RE_CHAPTER.match(t):
            k, seen_struct = "title", True
        elif prev == "chapter" and len(t) <= 60 and not re.match(r"^\d", t):
            k = "chaptername"
        elif RE_CAPTION.match(t):
            k = "caption"
        elif len(t) <= 90 and has_chapters and re.match(r"^\d+\.\d+\.\d+", t):
            k = "h2"
        elif len(t) <= 90 and has_chapters and re.match(r"^\d+\.\d+\s*\S", t):
            k = "h1"
        elif len(t) <= 90 and not has_chapters and re.match(r"^\d+\.\d+", t):
            k = "h2"
        elif len(t) <= 90 and not has_chapters and re.match(r"^\d+\.\s*\S", t) \
                and int(re.match(r"\d+", t).group()) > last_main:     # หัวข้อใหญ่เลขต้องเพิ่มขึ้นเรื่อย ๆ
            k = "h1"
            last_main = int(re.match(r"\d+", t).group())
        if k == "h1":
            seen_struct = True
        if not seen_struct and k not in ("title",):
            k = "cover" if k != "empty" else "empty"
        kinds.append(k)
        if k != "empty":
            prev = "chapter" if (k == "title" and RE_CHAPTER.match(t)) else k
    return kinds


# ───────────────────────── text-level checks (docx + pdf) ─────────────────────────
def text_checks(paras, kinds, doctype):
    """paras: list[str]; kinds: list[str]"""
    titles = [(i, norm(p)) for i, (p, k) in enumerate(zip(paras, kinds)) if k == "title"]
    names = [t.lower() for _, t in titles]

    # ภาษาวิชาการ
    for i, (p, k) in enumerate(zip(paras, kinds)):
        if k == "empty" or not p:
            continue
        t = norm(p)
        for w in (INFORMAL if k != "cover" else []):
            if w in t:
                add("warn", "ภาษา", f"คำไม่เป็นทางการ “{w}”", snip(t))
        for w in (PERSONAL if k != "cover" else []):
            if re.search(rf"(?:^|[\s(“\"]){re.escape(w)}", t) and not re.search(rf"{w}(?:ร่วง|ยาว|สั้น)", t):
                add("warn", "ภาษา", f"สรรพนาม/ความเห็นส่วนตัว “{w}” — ควรเน้นข้อมูล (ความเป็นปรนัย)", snip(t))
        for m in re.finditer(r"(?<![ก-๙A-Za-z.])(ผศ|รศ|ดร|อ)\.\s+(?=[ก-๙])", t):
            add("warn", "คำนำหน้านาม", f"“{m.group(0).strip()}” ควรเขียนติดชื่อไม่เว้นวรรค (เช่น ผศ.ดร.สมชาย)", snip(t))
        if "วิทยาศาสตร์บัณฑิต" in t:
            add("error", "สะกด", "“วิทยาศาสตร์บัณฑิต” → “วิทยาศาสตรบัณฑิต” (ไม่มีการันต์)", snip(t))
        if re.search(r"\bet al(?!\.)", t):
            add("error", "อ้างอิง", "“et al” ต้องมีจุด → “et al.”", snip(t))
        if re.search(r"ภาควิชาวิทยาการคอมพิวเตอร์|วิทยาการคอมพิวเตอร์\s*คณะวิทยาศาสตร์", t):
            add("warn", "ชื่อหน่วยงาน", "แม่แบบปัจจุบันใช้ “สาขาวิชาวิทยาการคอมพิวเตอร์ วิทยาลัยการคอมพิวเตอร์ มหาวิทยาลัยขอนแก่น”", snip(t))

    # ── โครงสร้าง
    def has(rx):
        return any(re.search(rx, norm(p)) for p in paras)

    if doctype == "report":
        need_front = ["บทคัดย่อ", "คำนำ", "สารบัญ", "สารบัญภาพ"]
        for f in need_front:
            if f not in names:
                add("error", "โครงสร้าง", f"ไม่พบส่วน “{f}” (Ass 4 กำหนด: ปกนอก บทคัดย่อ คำนำ สารบัญ สารบัญภาพ)")
        req = [(r"^บทที่\s*1", "บทที่ 1 บทนำ"), (r"^1\.1\s*ที่มา", "1.1 ที่มาและความสำคัญ"),
               (r"^1\.2\s*(จุดประสงค์|วัตถุประสงค์)", "1.2 จุดประสงค์ของการศึกษา"),
               (r"^1\.3\s*ขอบเขต", "1.3 ขอบเขตของการศึกษา"), (r"^1\.4\s*ประโยชน์", "1.4 ประโยชน์ที่คาดว่าจะได้รับ"),
               (r"^บทที่\s*2", "บทที่ 2 ทฤษฎีและงานวิจัยที่เกี่ยวข้อง"), (r"^2\.1\s*งานวิจัย", "2.1 งานวิจัยที่เกี่ยวข้อง"),
               (r"^2\.\d\s*เปรียบเทียบ", "2.3 เปรียบเทียบผลการศึกษา (synthesis matrix)"),
               (r"^บทที่\s*3", "บทที่ 3 สรุปผลการศึกษา"), (r"^3\.1\s*สรุป", "3.1 สรุปผล"),
               (r"^3\.2\s*แนวทาง", "3.2 แนวทางการนำไปใช้")]
        for rx, label in req:
            if not has(rx):
                add("warn", "โครงสร้าง", f"ไม่พบหัวข้อ “{label}” ตามโครงสร้าง Ass 4")
        if not any(n in ("เอกสารอ้างอิง", "references") for n in names):
            add("error", "โครงสร้าง", "ไม่พบ “เอกสารอ้างอิง” (ใช้รูปแบบ APA)")
        order = [n for n in names if n in ("บทคัดย่อ", "คำนำ", "สารบัญ", "สารบัญภาพ")]
        exp = [n for n in ["บทคัดย่อ", "คำนำ", "สารบัญ", "สารบัญภาพ"] if n in order]
        if order != exp:
            add("warn", "โครงสร้าง", f"ลำดับส่วนต้นคือ {order} — ตามที่กำหนดควรเป็น {exp}")
    elif doctype == "proposal":
        req = ["ชื่อหัวข้อโครงงาน", "หลักการและเหตุผล", "วัตถุประสงค์", "ทฤษฎีและผลงานวิจัยที่เกี่ยวข้อง",
               "วิธีดำเนินการวิจัย", "ขอบเขต", "สถานที่ทำวิจัย", "ประโยชน์ที่คาดว่าจะได้รับ",
               "แผนและระยะเวลาดำเนินการ", "งบประมาณ", "เอกสารอ้างอิง"]
        for n, h in enumerate(req, 1):
            if not has(rf"^\d+\.\s*{h[:8]}"):
                add("warn", "โครงสร้าง", f"ไม่พบหัวข้อ “{n}. {h}” ตามแบบเค้าโครงโครงงาน")
        extra = [(r"^CS\d{4}\s*/", "ปก: “CSxxxx/หมายเลขกลุ่ม” (20 pt หนา)"),
                 (r"^เค้าโครงโครงงานคอมพิวเตอร์$", "ปก: “เค้าโครงโครงงานคอมพิวเตอร์” (20 pt หนา)"),
                 (r"^รายงานนี้เป็นส่วนหนึ่งของการศึกษาวิชา", "ปก: “รายงานนี้เป็นส่วนหนึ่งของการศึกษาวิชา CP353761 …” (16 pt)"),
                 (r"^การเสนอเค้าโครงโครงงานคอมพิวเตอร์", "หัวหน้า 2: “การเสนอเค้าโครงโครงงานคอมพิวเตอร์” (18 pt หนา)"),
                 (r"Project Advisor", "ส่วนข้อมูลนักศึกษา: “Project Advisor”"),
                 (r"ตารางที่\s*\S+\s*แผน", "ข้อ 9: ตารางแผนและระยะเวลาดำเนินการ"),
                 (r"ลงชื่อผู้ทำโครงงาน", "ลงชื่อผู้ทำโครงงาน + วันที่ (ทุกคน)"),
                 (r"การตรวจสอบจากอาจารย์ที่ปรึกษา", "ช่อง “การตรวจสอบจากอาจารย์ที่ปรึกษาโครงงาน”")]
        for rx, label in extra:
            if not has(rx):
                add("warn", "โครงสร้าง", f"ไม่พบ {label} ตามแม่แบบเค้าโครงโครงงาน")
        for p in paras:
            t = norm(p)
            if re.match(r"^3\.\d+\s*\S", t) and not re.match(r"^3\.\d+\s*เพื่อ", t):
                add("warn", "เนื้อหา", "วัตถุประสงค์ข้อย่อยควรขึ้นต้นด้วย “เพื่อ…” และระบุผลลัพธ์ที่ได้ชัดเจน", snip(t))

    # ── บทคัดย่อ
    ab = [i for i, t in titles if t.lower() in ("บทคัดย่อ", "abstract")]
    for a in ab:
        body = []
        for j in range(a + 1, len(paras)):
            if kinds[j] == "title":
                break
            if norm(paras[j]):
                body.append(norm(paras[j]))
        txt = " ".join(body)
        if re.search(rf"\([^()]*{RE_YEAR}\)|\[\d+(?:[,–-]\s*\d+)*\]", txt):
            add("error", "บทคัดย่อ", "บทคัดย่อห้ามมีการอ้างอิง (in-text citation)")
        kw = [b for b in body if re.match(r"^(คำสำคัญ|keywords?)", b, re.I)]
        if not kw:
            add("warn", "บทคัดย่อ", "ไม่พบ “คำสำคัญ/Keywords” ท้ายบทคัดย่อ (3–5 คำ)")
        else:
            items = [x for x in re.split(r"[,，;]", re.sub(r"^(คำสำคัญ|keywords?)\s*[:：]?", "", kw[0], flags=re.I)) if x.strip()]
            if not 3 <= len(items) <= 5:
                add("warn", "บทคัดย่อ", f"คำสำคัญมี {len(items)} คำ — ควร 3–5 คำ")
        en_words = len(re.findall(r"[A-Za-z]+", txt))
        thai_chars = len(THAI.findall(txt))
        approx = en_words + round(thai_chars / 5)
        if approx > 300:
            add("warn", "บทคัดย่อ", f"ยาวประมาณ {approx} คำ — ควร 150–250 คำ หรือไม่เกิน 1 หน้า")
        if body and not any(re.search(r"(ผลการ(วิจัย|ศึกษา)|พบว่า|results?)", b, re.I) for b in body):
            add("warn", "บทคัดย่อ", "ไม่พบส่วนผลการศึกษา (“ผลการศึกษาพบว่า…”) — บทคัดย่อควรมี ที่มา/วัตถุประสงค์, วิธีการ, ผล, สรุป, คำสำคัญ")

    # ── เอกสารอ้างอิง
    heads = [(i, re.sub(r"^\d+\.\s*", "", norm(p)).lower()) for i, (p, k) in enumerate(zip(paras, kinds))
             if k in ("title", "h1")]
    r_idx = [i for i, t in heads if t in REF_HEADS]
    refs = []
    if r_idx:
        r0 = r_idx[-1]
        for j in range(r0 + 1, len(paras)):
            if kinds[j] in ("title", "h1") or re.match(r"^\(?(ลงชื่อ|การตรวจสอบจากอาจารย์)", norm(paras[j])):
                break                                    # จบที่หัวข้อถัดไป หรือส่วนลงชื่อท้ายเค้าโครง
            if norm(paras[j]):
                refs.append((j, norm(paras[j])))
    body_text = [norm(p) for p, k in zip(paras, kinds) if k not in ("cover", "empty")]
    if r_idx:
        body_text = [norm(p) for i, (p, k) in enumerate(zip(paras, kinds))
                     if i < r_idx[-1] and k not in ("cover", "empty")]
    ref_checks(refs, body_text, heads, dict(heads).get(r_idx[-1]) if r_idx else None)
    return refs


def thai_key(s):
    s = re.sub(r"^[\s\d.\[\]]+", "", s)
    s = re.sub(r"^([เแโใไ])(.)", r"\2\1", s)
    return re.sub("[" + chr(0x0E48) + "-" + chr(0x0E4C) + "]", "", s)


def ref_checks(refs, body_text, titles, head):
    if not refs:
        if not any(t in REF_HEADS for _, t in titles):
            return
        add("error", "อ้างอิง", "หัวข้อเอกสารอ้างอิงว่าง")
        return
    numbered = all(re.match(r"^\[?\d+[\].]", r) for _, r in refs)
    langs = ["th" if THAI.match(re.sub(r"^[\s\d.\[\]]+", "", r)) else "en" for _, r in refs]
    first_en = langs.index("en") if "en" in langs else None
    if first_en is not None and "th" in langs[first_en:] and not numbered:
        add("error", "อ้างอิง", "ต้องเรียงเอกสารภาษาไทยทั้งหมดก่อน แล้วจึงภาษาอังกฤษ",
            snip(refs[first_en + langs[first_en:].index("th")][1]))
    if not numbered:
        for lang in ("th", "en"):
            seq = [(r, thai_key(r) if lang == "th" else re.sub(r"^[\W\d_]+", "", r).lower())
                   for (_, r), l in zip(refs, langs) if l == lang]
            for (a, ka), (b, kb) in zip(seq, seq[1:]):
                if ka.startswith("______") or kb.startswith("______"):
                    continue
                if kb < ka:
                    add("warn", "อ้างอิง", "อาจไม่เรียงตามตัวอักษรชื่อผู้แต่ง (ตรวจซ้ำด้วยตา)", f"{snip(a, 25)} ↔ {snip(b, 25)}")
    prev_author = None
    for (_, r) in refs:
        rr = re.sub(r"^\[?\d+[\].]\s*", "", r)
        if not re.search(rf"[(\[]\s*{RE_YEAR}", rr) and not re.search(r"\(\d{4}, ", rr):
            add("warn", "อ้างอิง", "ไม่พบปีพิมพ์ในวงเล็บ (ปีพิมพ์) หลังชื่อผู้แต่ง", snip(rr))
        if re.search(r"\s+[.,:;)](?!\s*\.\s*\.)", rr) or re.search(r"\(\s+", rr):
            m = re.search(r".{0,12}(\s+[.,:;)]|\(\s+).{0,6}", rr)
            add("error", "อ้างอิง", f"มีช่องว่างหน้าเครื่องหมาย/ในวงเล็บ: “{m.group(0) if m else ''}” (เครื่องหมายต้องชิดตัวหน้า)", snip(rr))
        if re.search(r"\bet al(?!\.)", rr):
            add("error", "อ้างอิง", "“et al” ต้องมีจุด", snip(rr))
        if re.search(r"(https?://|www\.)", rr) and not re.search(r"(ค้นเมื่อ|Retrieved)", rr):
            add("error", "อ้างอิง", "เอกสารออนไลน์ต้องมี “ค้นเมื่อ วัน เดือน ปี, จาก URL” / “Retrieved Month D, YYYY, from URL”", snip(rr))
        author = re.split(r"\.\s|\s\(|\s\[", rr, maxsplit=1)[0].strip()
        if prev_author and author == prev_author and not author.startswith("___"):
            add("warn", "อ้างอิง", "ผู้แต่งคนแรกซ้ำรายการก่อนหน้า — คู่มือให้พิมพ์ “______.” แทนชื่อในรายการถัดไป", snip(rr))
        prev_author = author
        sp = re.findall(r"\)\.( +)\S", rr)
        if sp:
            ref_checks.spaces.update(len(s) for s in sp)
    if len(ref_checks.spaces) > 1:
        add("warn", "อ้างอิง", f"ระยะเว้นหลังเครื่องหมาย “).” ไม่สม่ำเสมอ ({dict(ref_checks.spaces)} เคาะ) — แนวปฏิบัติของรายวิชาให้ 2 เคาะหลัง . , : ;")

    # ── จับคู่อ้างอิงในเนื้อหา ↔ ท้ายเล่ม
    body = " ".join(body_text)
    cites = []
    if numbered:
        nums = set()
        for m in re.finditer(r"\[(\d+(?:\s*[,–-]\s*\d+)*)\]", body):
            for part in re.split(r"\s*,\s*", m.group(1)):
                if re.search(r"[–-]", part):
                    a, b = re.split(r"\s*[–-]\s*", part)
                    nums.update(range(int(a), int(b) + 1))
                else:
                    nums.add(int(part))
        for n in sorted(nums):
            if n > len(refs):
                add("error", "อ้างอิง", f"อ้าง [{n}] ในเนื้อหา แต่ท้ายเล่มมีเพียง {len(refs)} รายการ")
        if head in ("เอกสารอ้างอิง", "references"):
            for n in range(1, len(refs) + 1):
                if n not in nums:
                    add("warn", "อ้างอิง", f"รายการที่ {n} ไม่ถูกอ้างในเนื้อหา", snip(refs[n - 1][1]))
        return
    for m in re.finditer(r"\(([^()]*?(?:\([^()]*\)[^()]*?)?" + RE_YEAR + r"[^()]*)\)", body):
        for part in m.group(1).split(";"):
            part = part.strip()
            mm = re.match(rf"(.+?),\s*({RE_YEAR})", part)
            if mm:
                cites.append((mm.group(1).strip(), mm.group(2), part))
    for m in re.finditer(rf"([A-Z][A-Za-z'\-]+)(?: et al\.| and [A-Z][A-Za-z'\-]+)? \(({RE_YEAR})", body):
        cites.append((m.group(1), m.group(2), m.group(0)))
    for m in re.finditer(rf"([ก-๙]+ [ก-๙]+)(?: และคณะ)? \(({RE_YEAR})", body):
        cites.append((m.group(1), m.group(2), m.group(0)))
    used = set()
    for author, year, raw in cites:
        a = re.sub(r"(\s*(&|and|และ).*|\s+et al\..*|\s+และคณะ.*)$", "", author).strip()
        a = re.sub(r"^(อ้างถึงใน|cited in)\s*", "", a)
        key = a.split()[0] if THAI.match(a) else (a.split()[-1] if " " in a and not a[0].isupper() else a.split()[0])
        key = key.strip(",(")
        y = year.split()[0]
        hit = [k for k, (_, r) in enumerate(refs) if key and key in r and y in r]
        if hit:
            used.update(hit)
        elif len(key) > 1:
            add("error", "อ้างอิง", f"อ้าง “{raw}” ในเนื้อหา แต่ไม่พบในรายการท้ายเล่ม (ชื่อ/ปีไม่ตรง?)")
    if head in ("เอกสารอ้างอิง", "references"):
        for k, (_, r) in enumerate(refs):
            if k not in used:
                add("warn", "อ้างอิง", "รายการท้ายเล่มไม่ถูกอ้างในเนื้อหา (หัวข้อ “เอกสารอ้างอิง” ต้องมีเฉพาะที่อ้าง)", snip(r))


ref_checks.spaces = Counter()

def docx_mode(path, doctype, fix_out):
    from docx import Document
    from docx.enum.text import WD_ALIGN_PARAGRAPH
    from docx.oxml import OxmlElement
    from docx.oxml.ns import qn
    from docx.shared import Inches, Pt
    from docx.table import Table
    from docx.text.paragraph import Paragraph

    doc = Document(path)
    body_items = []
    for el in doc.element.body.iterchildren():
        if el.tag == qn("w:p"):
            body_items.append(("p", Paragraph(el, doc)))
        elif el.tag == qn("w:tbl"):
            body_items.append(("tbl", Table(el, doc)))
    paras = [x for t, x in body_items if t == "p"]
    texts = [p.text for p in paras]
    has_ch = any(RE_CHAPTER.match(norm(t)) for t in texts)
    if doctype == "auto":
        doctype = "report" if has_ch else ("proposal" if any("หลักการและเหตุผล" in t for t in texts) else "generic")
    kinds = classify(texts, has_ch)

    # ── ปก/หัวเอกสารเค้าโครง (ตามแม่แบบ: 20 หนา / 20 ปกติ / 18 ปกติ / 16 ปกติ)
    cover_spec = {}
    if doctype == "proposal":
        in_title = False
        for i, (t, k) in enumerate(zip(texts, kinds)):
            if k != "cover":
                continue
            t = norm(t)
            spec = None
            if re.match(r"^CS\d{4}\s*/", t) or t == "เค้าโครงโครงงานคอมพิวเตอร์":
                spec, in_title = (20, True), t == "เค้าโครงโครงงานคอมพิวเตอร์"
            elif t == "โดย":
                spec, in_title = (18, False), False
            elif in_title and t:
                spec = (20, False)                                   # ชื่อเรื่องไทย/อังกฤษ
            elif re.match(r"^\d{9}-?\d?\s", t) or re.match(r"^อาจารย์ที่ปรึกษา(?!โครงงาน)", t):
                spec = (18, False)
            elif re.match(r"^(รายงานนี้เป็นส่วนหนึ่ง|ภาคเรียนที่|มหาวิทยาลัยขอนแก่น$|\(เดือน|\(.*พ\.ศ\.)", t):
                spec = (16, False)
            elif t == "การเสนอเค้าโครงโครงงานคอมพิวเตอร์":
                spec = (18, True)
            elif t.startswith("สาขาวิชาวิทยาการคอมพิวเตอร์"):
                spec = (16, False)
            if spec:
                cover_spec[i] = spec

    # ── page setup
    for si, s in enumerate(doc.sections):
        w, h = s.page_width.inches, s.page_height.inches
        if abs(w - A4[0]) > TOL or abs(h - A4[1]) > TOL:
            add("error", "หน้ากระดาษ", f"section {si+1}: ขนาด {w:.2f}×{h:.2f} นิ้ว — ต้องเป็น A4 (8.27×11.69)")
        for side, want in MARGINS.items():
            got = getattr(s, f"{side}_margin").inches
            if abs(got - want) > TOL:
                add("error", "หน้ากระดาษ", f"section {si+1}: ขอบ{dict(top='บน', left='ซ้าย', right='ขวา', bottom='ล่าง')[side]} {got:.2f}\" — ต้อง {want}\"")
        if s.header_distance is not None and abs(s.header_distance.inches - HEADER_DIST) > TOL:
            add("warn", "เลขหน้า", f"section {si+1}: ระยะ header {s.header_distance.inches:.2f}\" — ตัวอย่างกำหนดเลขหน้าห่างขอบบน 0.5\"")
        if fix_out:
            s.page_width, s.page_height = Inches(A4[0]), Inches(A4[1])
            for side, want in MARGINS.items():
                setattr(s, f"{side}_margin", Inches(want))
            s.header_distance = Inches(HEADER_DIST)
    if fix_out:
        fixed.append("ตั้งหน้ากระดาษ A4, ขอบ บน/ซ้าย 1.5\" ขวา/ล่าง 1\", header 0.5\" ทุก section")

    # ── page numbers
    def has_page_field(part):
        x = part._element.xml
        return "PAGE" in x and ("fldSimple" in x or "instrText" in x)

    s0 = doc.sections[0]
    if not any(has_page_field(s.header) for s in doc.sections):
        where = "footer" if any(has_page_field(s.footer) for s in doc.sections) else None
        add("error", "เลขหน้า", "ไม่พบเลขหน้าที่มุมขวาบน" + (" (พบใน footer — ต้องย้ายไป header ชิดขวา)" if where else ""))
        if fix_out:
            for s in doc.sections:
                if s.header.is_linked_to_previous and s is not s0:
                    continue
                p = s.header.add_paragraph()
                p.alignment = WD_ALIGN_PARAGRAPH.RIGHT
                fld = OxmlElement("w:fldSimple")
                fld.set(qn("w:instr"), "PAGE")
                r = OxmlElement("w:r")
                t = OxmlElement("w:t")
                t.text = "1"
                r.append(t)
                fld.append(r)
                p._p.append(fld)
            fixed.append("เพิ่มเลขหน้า (PAGE field) ชิดขวาใน header")
    else:
        for s in doc.sections:
            for p in s.header.paragraphs:
                if "PAGE" in p._p.xml and p.alignment not in (WD_ALIGN_PARAGRAPH.RIGHT,):
                    add("warn", "เลขหน้า", "เลขหน้าควรชิดขวา (มุมขวาบน)")
                    if fix_out:
                        p.alignment = WD_ALIGN_PARAGRAPH.RIGHT
                        fixed.append("จัดเลขหน้าชิดขวา")
    if not s0.different_first_page_header_footer:
        add("error", "เลขหน้า", "หน้าแรกต้องไม่แสดงเลขหน้า (เปิด Different First Page)")
        if fix_out:
            s0.different_first_page_header_footer = True
            fixed.append("เปิด Different First Page — ซ่อนเลขหน้าหน้าแรก")
    elif has_page_field(s0.first_page_header):
        add("error", "เลขหน้า", "หน้าแรกมีเลขหน้า — ต้องไม่ใส่")

    # ── run-property resolution
    styles_root = doc.styles.element
    dd = styles_root.find(qn("w:docDefaults"))
    dd_rpr = dd.find(qn("w:rPrDefault") + "/" + qn("w:rPr")) if dd is not None else None

    def chain(style):
        while style is not None:
            yield style.element.find(qn("w:rPr"))
            style = style.base_style

    def resolve(run, para, getter):
        cands = [run._r.rPr]
        try:
            if run.style is not None:
                cands += list(chain(run.style))
        except Exception:
            pass
        cands += list(chain(para.style)) + [dd_rpr]
        for rpr in cands:
            if rpr is None:
                continue
            v = getter(rpr)
            if v is not None:
                return v
        return None

    def g_font(attr, theme):
        def f(rpr):
            rf = rpr.find(qn("w:rFonts"))
            if rf is None:
                return None
            if rf.get(qn(f"w:{theme}")):
                return f"(theme:{rf.get(qn(f'w:{theme}'))})"
            return rf.get(qn(f"w:{attr}"))
        return f

    def g_size(tag):
        def f(rpr):
            e = rpr.find(qn(f"w:{tag}"))
            return int(e.get(qn("w:val"))) / 2 if e is not None and e.get(qn("w:val")) else None
        return f

    def g_bool(tag):
        def f(rpr):
            e = rpr.find(qn(f"w:{tag}"))
            if e is None:
                return None
            return e.get(qn("w:val")) not in ("0", "false", "off")
        return f

    def run_props(run, para):
        t = run.text
        thai = bool(THAI.search(t))
        font = resolve(run, para, g_font("cs", "cstheme") if thai else g_font("ascii", "asciiTheme"))
        size = resolve(run, para, g_size("szCs" if thai else "sz")) or resolve(run, para, g_size("sz"))
        bold = resolve(run, para, g_bool("bCs" if thai else "b"))
        if bold is None:
            bold = resolve(run, para, g_bool("b"))
        return font, size, bool(bold)

    def set_run(run, size=None, bold=None):
        rpr = run._r.get_or_add_rPr()
        rf = rpr.find(qn("w:rFonts"))
        if rf is None:
            rf = OxmlElement("w:rFonts")
            rpr.insert(0, rf)
        for a in ("ascii", "hAnsi", "cs", "eastAsia"):
            rf.set(qn(f"w:{a}"), FONT)
        for a in ("asciiTheme", "hAnsiTheme", "cstheme", "eastAsiaTheme"):
            if rf.get(qn(f"w:{a}")) is not None:
                del rf.attrib[qn(f"w:{a}")]
        if size is not None:
            run.font.size = Pt(size)
            e = rpr.find(qn("w:szCs"))
            if e is None:
                e = OxmlElement("w:szCs")
                rpr.append(e)
            e.set(qn("w:val"), str(int(size * 2)))
        if bold is not None:
            run.font.bold = bold
            e = rpr.find(qn("w:bCs"))
            if e is None:
                e = OxmlElement("w:bCs")
                rpr.append(e)
            e.set(qn("w:val"), "1" if bold else "0")

    # ── fonts / sizes per paragraph kind
    want = {"title": (18, True), "chaptername": (18, True), "h1": (16, True), "h2": (14, None), "body": (14, None)}
    badfont, badsize = Counter(), Counter()
    ex_font, ex_size = {}, {}

    def scan_para(p, k, in_table=False, spec=None):
        said = set()
        for r in p.runs:
            if not r.text.strip():
                continue
            font, size, bold = run_props(r, p)
            if font != FONT:
                badfont[font] += 1
                ex_font.setdefault(font, snip(p.text, 30))
            if spec:
                ws, wb = spec
                if size is not None and abs(size - ws) > 0.1 and "s" not in said:
                    said.add("s")
                    add("error", "ปก", f"ขนาด {size:g} pt — แม่แบบกำหนด {ws} pt", snip(p.text))
                if bold != wb and "b" not in said:
                    said.add("b")
                    add("error", "ปก", "ต้องเป็นตัวหนา" if wb else "ต้องเป็นตัวปกติ (ไม่หนา)", snip(p.text))
                if fix_out:
                    set_run(r, ws, wb)
                continue
            if k in want and not in_table:
                ws, wb = want[k]
                if size is not None and abs(size - ws) > 0.1:
                    if k in ("title", "chaptername", "h1", "h2"):
                        add("error", "ขนาดตัวอักษร", f"{dict(title='ชื่อบท/ชื่อส่วน', chaptername='ชื่อบท', h1='หัวข้อใหญ่', h2='หัวข้อย่อย')[k]} ขนาด {size:g} pt — ต้อง {ws} pt", snip(p.text))
                    else:
                        badsize[size] += 1
                        ex_size.setdefault(size, snip(p.text, 30))
                if wb and not bold and k != "body" and "b" not in said:
                    said.add("b")
                    add("error", "ตัวหนา", f"{'ชื่อบท/ชื่อส่วน' if k in ('title','chaptername') else 'หัวข้อใหญ่'} ต้องเป็นตัวหนา", snip(p.text))
                if k == "h2" and bold and "h2" not in said:
                    said.add("h2")
                    add("info", "ตัวหนา", "หัวข้อย่อยตามแนวปฏิบัติใช้ตัวพิมพ์ปกติ 14 pt (ตัวอย่างไม่ทำตัวหนา)", snip(p.text))
            if fix_out:
                if k in want and not in_table and k != "cover":
                    ws, wb = want[k]
                    set_run(r, ws, wb)
                else:
                    set_run(r)

    for i, (p, k) in enumerate(zip(paras, kinds)):
        scan_para(p, k, spec=cover_spec.get(i))
    for t, x in body_items:
        if t == "tbl":
            for row in x.rows:
                for c in row.cells:
                    for p in c.paragraphs:
                        scan_para(p, "body", in_table=True)
    for f in [f for f in badfont if f in ALT_FONTS]:
        add("warn", "ฟอนต์", f"ใช้ {f} {badfont.pop(f)} ช่วงข้อความ — แม่แบบเค้าโครงใช้ {f} แต่แนวปฏิบัติกำหนด {FONT} (ถามอาจารย์ว่ายึดแบบไหน)", ex_font.get(f, ""))
    for f, n in badfont.items():
        add("error", "ฟอนต์", f"ใช้ฟอนต์ {f or '(ไม่ระบุ/ค่าเริ่มต้น)'} {n} ช่วงข้อความ — ต้องเป็น {FONT} ทั้งเล่ม", ex_font.get(f, ""))
    for s, n in badsize.items():
        add("error", "ขนาดตัวอักษร", f"เนื้อหาขนาด {s:g} pt {n} ช่วงข้อความ — เนื้อหาต้อง 14 pt", ex_size.get(s, ""))
    if fix_out:
        for st in doc.styles:
            try:
                rpr = st.element.get_or_add_rPr()
            except Exception:
                continue
            rf = rpr.find(qn("w:rFonts"))
            if rf is None:
                rf = OxmlElement("w:rFonts")
                rpr.insert(0, rf)
            for a in ("ascii", "hAnsi", "cs", "eastAsia"):
                rf.set(qn(f"w:{a}"), FONT)
            for a in ("asciiTheme", "hAnsiTheme", "cstheme", "eastAsiaTheme"):
                rf.attrib.pop(qn(f"w:{a}"), None)
        fixed.append(f"เปลี่ยนฟอนต์ทุก run และทุก style เป็น {FONT}; ตั้งขนาด ชื่อบท 18 หนา / หัวข้อใหญ่ 16 หนา / หัวข้อย่อย+เนื้อหา 14")

    # ── captions (ตาราง/ภาพ)
    nums = {"t": [], "f": []}
    flat = body_items
    for idx, (t, x) in enumerate(flat):
        if t != "p":
            continue
        txt = norm(x.text)
        m = RE_CAPTION.match(txt)
        if not m:
            continue
        kind = "t" if m.group(1).lower() in ("ตารางที่", "table") else "f"
        label = "ตาราง" if kind == "t" else "ภาพ"
        num = m.group(2).rstrip(".")
        cont = bool(re.search(r"\((ต่อ|cont\.?)\)\s*$", txt, re.I))
        if "." in num:
            add("warn", "ตาราง/ภาพ", f"เลข{label} “{num}” — เอกสารกำหนดให้เรียงต่อเนื่องทั้งเล่ม ({label}ที่ 1, 2, 3 …)", snip(txt))
        elif not cont:
            nums[kind].append(int(num))
        if m.group(1) in ("ตารางที่", "ภาพที่") and not re.match(rf"^{m.group(1)} \d+  \S", txt):
            add("warn", "ตาราง/ภาพ", f"รูปแบบควรเป็น “{m.group(1)}␣{num}␣␣ชื่อ{label}” (เว้น 1 เคาะหลัง “ที่”, 2 เคาะก่อนชื่อ)", snip(txt))
        flags = [(ch, run_props(r, x)[2]) for r in x.runs for ch in r.text]
        raw = "".join(ch for ch, _ in flags)
        lm = re.match(r"\s*\S+\s*[\d.]+", raw)
        lab_b = [b for ch, b in flags[:lm.end()] if ch.strip()] if lm else []
        tit_b = [b for ch, b in flags[lm.end():] if ch.strip()] if lm else []
        lab_runs_ok = bool(lab_b) and all(lab_b) and not any(tit_b)
        if not lab_runs_ok:
            add("warn", "ตาราง/ภาพ", f"“{m.group(1)} {num}” ต้องเป็นตัวหนา และชื่อ{label}เป็นตัวปกติ", snip(txt))
        nxt = [tt for tt, xx in flat[idx + 1: idx + 3] if not (tt == "p" and not norm(xx.text) and "graphic" not in xx._p.xml)]
        prv = [(tt, xx) for tt, xx in flat[max(0, idx - 2): idx]]
        if kind == "t":
            if not nxt or nxt[0] != "tbl":
                add("warn", "ตาราง/ภาพ", "ชื่อตารางต้องอยู่เหนือตาราง (ไม่พบตารางต่อจากชื่อ)", snip(txt))
            if x.alignment in (WD_ALIGN_PARAGRAPH.CENTER, WD_ALIGN_PARAGRAPH.RIGHT):
                add("error", "ตาราง/ภาพ", "ลำดับและชื่อตารางต้องชิดขอบซ้าย", snip(txt))
                if fix_out:
                    x.alignment = WD_ALIGN_PARAGRAPH.LEFT
                    fixed.append(f"จัดชื่อตารางชิดซ้าย: {snip(txt, 25)}")
        else:
            if not any(tt == "p" and ("graphic" in xx._p.xml or "pict" in xx._p.xml) for tt, xx in prv):
                add("warn", "ตาราง/ภาพ", "ชื่อภาพต้องอยู่ใต้ภาพ (ไม่พบรูปภาพก่อนชื่อ)", snip(txt))
        if fix_out and m.group(1) in ("ตารางที่", "ภาพที่"):
            title = re.sub(r"^\S+\s*[\d.]+\.?\s*", "", txt)
            new_label = f"{m.group(1)} {num}"
            if not lab_runs_ok or not re.match(rf"^{m.group(1)} \d+  \S", txt):
                for r in list(x.runs):
                    r._r.getparent().remove(r._r)
                set_run(x.add_run(new_label), 14, True)
                set_run(x.add_run("  " + title), 14, False)
                fixed.append(f"จัดรูปแบบชื่อ{label}: “{new_label}␣␣{snip(title, 20)}”")
    for kind, seq in nums.items():
        label = "ตาราง" if kind == "t" else "ภาพ"
        if seq and seq != list(range(1, len(seq) + 1)):
            add("error", "ตาราง/ภาพ", f"เลข{label}ไม่ต่อเนื่อง: {seq} — ต้องเรียง 1, 2, 3 … ตลอดเล่ม")
    if not nums["f"] and doctype == "report" and any(t == "p" and "graphic" in x._p.xml for t, x in flat[5:]):
        add("warn", "ตาราง/ภาพ", "มีรูปภาพในเนื้อหาแต่ไม่พบคำบรรยาย “ภาพที่ …”")

    # ── reference paragraph formatting
    refs = text_checks(texts, kinds, doctype)
    ref_idx = {j for j, _ in refs}
    no_hang = 0
    for j in ref_idx:
        p = paras[j]
        pf = p.paragraph_format
        fli = pf.first_line_indent
        if not (fli is not None and fli < 0) and not (pf.left_indent and fli is not None and fli < 0):
            no_hang += 1
        if fix_out:
            for r in p.runs:
                new = re.sub(r"\(\s+", "(", re.sub(r"(?<=\S)\s+(?=[,:;)])", "", r.text))
                new = re.sub(r"(?<=[^\s.])\s+\.(?=\s|$)", ".", new)
                if new != r.text:
                    r.text = new
                    fixed.append(f"ลบช่องว่างหน้าเครื่องหมายในรายการอ้างอิง: {snip(p.text, 25)}")
            for r in p.runs:
                if re.search(r"\bet al(?!\.)", r.text):
                    r.text = re.sub(r"\bet al(?!\.)", "et al.", r.text)
                    fixed.append("แก้ “et al” → “et al.” ในรายการอ้างอิง")
            pf.left_indent = Inches(0.5)
            pf.first_line_indent = Inches(-0.5)
    if no_hang:
        add("warn", "อ้างอิง", f"{no_hang} รายการไม่มีการเยื้องบรรทัดถัดไป (hanging indent ~4–8 ตัวอักษร)")
        if fix_out:
            fixed.append("ตั้ง hanging indent 0.5\" ให้รายการเอกสารอ้างอิง")

    if fix_out:
        # et al. / สะกด / คำนำหน้านาม (แก้เฉพาะภายใน run เดียว)
        for p, k in zip(paras, kinds):
            for r in p.runs:
                new = r.text.replace("วิทยาศาสตร์บัณฑิต", "วิทยาศาสตรบัณฑิต")
                new = re.sub(r"(?<![ก-๙A-Za-z.])(ผศ|รศ|ดร)\.\s+(?=[ก-๙])", r"\1.", new)
                if new != r.text:
                    r.text = new
                    fixed.append("แก้ “วิทยาศาสตรบัณฑิต” / ลบวรรคหลังคำนำหน้านามวิชาการ (ผศ./รศ./ดร.)")
                if re.search(r"\bet al(?!\.)", r.text):
                    r.text = re.sub(r"\bet al(?!\.)", "et al.", r.text)
                    fixed.append("แก้ “et al” → “et al.”")
        # เรียงรายการอ้างอิง: ไทยก่อน อังกฤษ (คงลำดับเดิมภายในภาษา)
        rp = [paras[j] for j, _ in refs]
        numbered = rp and all(re.match(r"^\[?\d+[\].]", norm(p.text)) for p in rp)
        if rp and not numbered:
            is_th = [bool(THAI.match(norm(p.text))) for p in rp]
            order = [p for p, th in zip(rp, is_th) if th] + [p for p, th in zip(rp, is_th) if not th]
            if order != rp:
                anchor = rp[0]._p.getprevious()
                for p in rp:
                    p._p.getparent().remove(p._p)
                for p in reversed(order):
                    anchor.addnext(p._p)
                fixed.append("ย้ายรายการอ้างอิงภาษาไทยขึ้นก่อนภาษาอังกฤษ (ตรวจลำดับตัวอักษรอีกครั้ง)")
        doc.save(fix_out)
    return doctype

def pdf_mode(path, doctype):
    import pdfplumber
    lines_all, fonts, sizes = [], Counter(), Counter()
    with pdfplumber.open(path) as pdf:
        for pi, page in enumerate(pdf.pages):
            W, H = page.width / 72, page.height / 72
            if pi == 0 and (abs(W - A4[0]) > TOL or abs(H - A4[1]) > TOL):
                add("error", "หน้ากระดาษ", f"ขนาด {W:.2f}×{H:.2f} นิ้ว — ต้องเป็น A4")
            chars = [c for c in page.chars if c["text"].strip()]
            if not chars:
                continue
            for c in chars:
                fonts[re.sub(r"^[A-Z]{6}\+", "", c["fontname"])] += 1
                sizes[round(c["size"])] += 1
            body = [c for c in chars if c["top"] > 1.0 * 72]
            if body and pi > 0:
                L = min(c["x0"] for c in body) / 72
                T = min(c["top"] for c in body) / 72
                R = W - max(c["x1"] for c in body) / 72
                if L < MARGINS["left"] - 0.15:
                    add("error", "หน้ากระดาษ", f"หน้า {pi+1}: ขอบซ้ายประมาณ {L:.2f}\" (< 1.5\")")
                if R < MARGINS["right"] - 0.15:
                    add("warn", "หน้ากระดาษ", f"หน้า {pi+1}: ข้อความล้นขอบขวา (เหลือ {R:.2f}\" < 1\")")
                if T < MARGINS["top"] - 0.25:
                    add("warn", "หน้ากระดาษ", f"หน้า {pi+1}: ขอบบนประมาณ {T:.2f}\" (< 1.5\")")
            head = [c for c in chars if c["top"] < 1.0 * 72]
            htxt = "".join(c["text"] for c in head).strip()
            if pi == 0 and re.fullmatch(r"[\dก-ฮ]{1,3}", htxt or "-"):
                add("error", "เลขหน้า", "หน้าแรกมีเลขหน้า — ต้องไม่ใส่")
            if pi > 0 and not re.search(r"\d|[กขคง]", htxt):
                foot = "".join(c["text"] for c in chars if c["bottom"] > page.height - 0.9 * 72).strip()
                if re.fullmatch(r"\d{1,3}", foot):
                    add("error", "เลขหน้า", f"หน้า {pi+1}: เลขหน้าอยู่ด้านล่าง — ต้องอยู่มุมขวาบน")
            for ln in page.extract_text_lines(layout=False, strip=True):
                cs = [c for c in ln["chars"] if c["text"].strip()]
                if not cs:
                    continue
                sz = Counter(round(c["size"]) for c in cs).most_common(1)[0][0]
                bold = sum("bold" in c["fontname"].lower() for c in cs) > len(cs) / 2
                lines_all.append(dict(text=ln["text"], x0=ln["x0"], top=ln["top"], size=sz, bold=bold, page=pi + 1))
    alltxt = "".join(l["text"] for l in lines_all)
    cid = len(re.findall(r"\(cid:\d+\)", alltxt))
    if cid > max(5, len(alltxt) * 0.003):
        add("warn", "PDF", f"PDF นี้ถอดข้อความภาษาไทยได้ไม่สมบูรณ์ ({cid} ตัวอักษรเสีย) — ผลตรวจภาษา/หัวข้อ/อ้างอิงอาจคลาดเคลื่อน ให้ขอไฟล์ .docx หรือดูภาพหน้าเอกสารประกอบ")
    for l in lines_all:
        l["text"] = re.sub(r"\(cid:\d+\)", "", l["text"])
    psk = sum(n for f, n in fonts.items() if "sarabunpsk" in f.lower().replace(" ", ""))
    if psk > 20:
        add("warn", "ฟอนต์", f"ใช้ TH SarabunPSK ({psk} ตัวอักษร) — แม่แบบเค้าโครงใช้ตัวนี้ แต่แนวปฏิบัติกำหนด {FONT}")
    non = {f: n for f, n in fonts.items() if "sarabun" not in f.lower() and n > 20}
    for f, n in non.items():
        add("error", "ฟอนต์", f"ใช้ฟอนต์ {f} ({n} ตัวอักษร) — ต้องเป็น {FONT}")
    total = sum(sizes.values())
    if total and sizes.most_common(1)[0][0] != 14:
        add("error", "ขนาดตัวอักษร", f"ขนาดเนื้อหาหลัก {sizes.most_common(1)[0][0]} pt — ต้อง 14 pt")
    # รวมบรรทัดเป็นย่อหน้า (ย่อหน้าใหม่เมื่อบรรทัดเริ่มที่ขอบซ้าย/เยื้อง หรือหัวข้อ)
    paras, meta = [], []
    left = Counter(round(l["x0"]) for l in lines_all).most_common(1)[0][0] if lines_all else 0
    in_refs = False
    for l in lines_all:
        t = norm(l["text"])
        if re.fullmatch(r"[\dก-ฮ]{1,3}", t):
            continue
        structural = bool(RE_CAPTION.match(t) or is_front(t) or RE_CHAPTER.match(t)
                          or re.match(r"^\d+(\.\d+)*\.?\s+\S", t) and len(t) <= 90)
        if is_front(t) or RE_CHAPTER.match(t):
            in_refs = norm(t).lower() in REF_HEADS
        if in_refs:      # รายการอ้างอิง: บรรทัดแรกชิดซ้าย บรรทัดต่อไปเยื้อง
            newp = structural or l["x0"] <= left + 3
        else:            # ย่อหน้าปกติ: บรรทัดแรกเยื้อง
            newp = structural or l["x0"] > left + 3 or (meta and meta[-1]["size"] != l["size"])
        if newp or not paras:
            paras.append(t)
            meta.append(l)
        else:
            paras[-1] += ("" if THAI.match(t[:1] or "a") and THAI.search(paras[-1][-1:]) else " ") + t
    has_ch = any(RE_CHAPTER.match(p) for p in paras)
    if doctype == "auto":
        doctype = "report" if has_ch else ("proposal" if any("หลักการและเหตุผล" in p for p in paras) else "generic")
    kinds = classify(paras, has_ch)
    for p, k, m in zip(paras, kinds, meta):
        exp = {"title": 18, "chaptername": 18, "h1": 16}.get(k)
        if exp and abs(m["size"] - exp) > 0.6:
            add("error", "ขนาดตัวอักษร", f"หน้า {m['page']}: “{snip(p, 30)}” ขนาด {m['size']} pt — ต้อง {exp} pt")
        if exp and not m["bold"]:
            add("warn", "ตัวหนา", f"หน้า {m['page']}: “{snip(p, 30)}” ควรเป็นตัวหนา")
    text_checks(paras, kinds, doctype)
    add("info", "PDF", "ตรวจจาก PDF ได้เฉพาะสิ่งที่มองเห็น — แก้ไขอัตโนมัติไม่ได้ ควรตรวจไฟล์ .docx ต้นฉบับ")
    return doctype


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("input")
    ap.add_argument("--type", default="auto", choices=["auto", "report", "proposal", "generic"])
    ap.add_argument("--fix")
    ap.add_argument("--json")
    a = ap.parse_args()
    if a.input.lower().endswith(".pdf"):
        dt = pdf_mode(a.input, a.type)
    else:
        dt = docx_mode(a.input, a.type, a.fix)
    # de-dup
    seen, out = set(), []
    for i in issues:
        k = (i["sev"], i["cat"], i["msg"], i["where"])
        if k not in seen:
            seen.add(k)
            out.append(i)
    icon = {"error": "❌", "warn": "⚠️", "info": "ℹ️"}
    print(f"# ผลตรวจ: {a.input}  (ชนิดเอกสาร: {dt})")
    c = Counter(i["sev"] for i in out)
    print(f"❌ ผิดกฎ {c['error']}  ⚠️ ควรตรวจ {c['warn']}  ℹ️ {c['info']}\n")
    for sev in ("error", "warn", "info"):
        for i in [x for x in out if x["sev"] == sev]:
            w = f"  — “{i['where']}”" if i["where"] else ""
            print(f"{icon[sev]} [{i['cat']}] {i['msg']}{w}")
    if fixed:
        print("\n## แก้ไขอัตโนมัติแล้ว → " + a.fix)
        for f in dict.fromkeys(fixed):
            print("✅ " + f)
    if a.json:
        json.dump(dict(type=dt, issues=out, fixed=list(dict.fromkeys(fixed))), open(a.json, "w", encoding="utf8"),
                  ensure_ascii=False, indent=1)


if __name__ == "__main__":
    main()
```
